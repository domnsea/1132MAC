This zip is ChurchGuestZoom.app (not a .command file).
Earlier zips did nothing after you opened them: macOS saved the
.command as text, Terminal flashed closed, or the script hung with
no window (sudo password, stuck End Meeting quit, missing python3).

HOW TO RUN

1. Quit 1132wtf-v94 first.
2. Unzip this file. Drag ChurchGuestZoom.app to the Desktop.
3. Right-click ChurchGuestZoom.app → Open → Open.
   (Double-click may be blocked by Gatekeeper the first time.)
4. A window MUST appear immediately: "Church Guest Zoom is starting."
   If you get no window, this is not the H zip. Download again.
5. Click Continue. Enter your Mac password if asked.
6. Click Allow if Keychain Access asks.
7. Zoom opens with a random 6-digit name. Leave the app in the Dock
   until you quit Zoom. Your gamer Zoom comes back after that.

A log is written to Desktop/ChurchGuestZoom-log.txt.

Do not use BALLROOM_Mac_Universal_Reset_Kit.zip for church.
Do not open a raw .command from GitHub (browsers save that as text).
